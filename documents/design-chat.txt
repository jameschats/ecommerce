Since you are a Technical Architect with strong .NET + Angular experience and you're looking at this as a master system design project, I would not recommend starting with a Flipkart-scale mindset.

Instead, build something that sits between:

Small: Shopify store
Medium: Myntra / Nykaa in their early years
Large: Flipkart / Amazon

This gives you enough complexity to learn real-world architecture without getting overwhelmed.

adding products/products details, can we do this using a file?

Yes. In fact, for an e-commerce platform, bulk upload via files is not just a nice feature—it is almost mandatory.

Nobody wants to manually enter:

10,000 Products
50,000 Products
100,000 Products

through admin screens.

Recommendation

Support both:

Option 1: Manual Entry

Useful for:

Single product updates
Corrections
Small catalogs
Option 2: File Upload

Useful for:

Initial product import
Mass updates
Vendor catalogs
Start with Excel

Most business users understand Excel.

Example
SKU	Product Name	Category	Brand	Price	Stock
BAT001	Dell Battery 65Wh	Batteries	Dell	1200	50
BAT002	HP Battery 45Wh	Batteries	HP	1100	20

Admin uploads:

products.xlsx

System validates and imports.

Product Attributes

Instead of fixed columns, allow dynamic columns.

Example:

SKU	Product Name	Warranty	Compatible Model
BAT001	Dell Battery	1 Year	Dell Latitude 5420

Maps into:

ProductAttributes

automatically.

Product Images
Option A

Excel contains image URLs

SKU	ImageUrl
BAT001	https://site.com/images/bat001.jpg

System downloads images.

Option B

ZIP Upload

products.xlsx
images.zip

Images named:

BAT001.jpg
BAT002.jpg

System matches SKU to image.

This is how many enterprise systems work.
